# Aplicación repo_cars

Esta aplicación permite visualizar datos de un archivo CSV mediante gráficos interactivos creados con Plotly.  
Incluye un encabezado y un botón que genera un histograma de una columna seleccionada del dataset.  

## Funcionalidad principal
- Lectura de datos desde un archivo CSV.
- Visualización de histogramas interactivos con Plotly.
- Interfaz sencilla y rápida.

## Cómo ejecutar la aplicación
* Clona el repositorio:
```
https://github.com/kariglz/repo_cars.git
```
* Instala desde la terminal:
```
   pip install -r requirements.txt
```
* Ejecuta la aplicación:
```
    streamlit run app.py
```
